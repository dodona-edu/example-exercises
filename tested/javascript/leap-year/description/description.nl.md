Schrijf een functie `isLeapYear` die een jaartal als argument aanvaardt.
Deze functie moet `true` teruggeven als het jaar een schrikkeljaar is en anders `false`.

Een jaar is een schrikkeljaar als het deelbaar is door 4, behalve als het deelbaar is door 100.
Jaren die deelbaar zijn door 400 zijn wel weer schrikkeljaren.

### Voorbeeld

```console?lang=javascript&prompt=>
> isLeapYear(2024)
true
> isLeapYear(1900)
false
```
