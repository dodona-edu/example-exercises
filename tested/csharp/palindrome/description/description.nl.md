Schrijf een functie `IsPalindrome` die een woord als argument aanvaardt.
De functie moet `true` teruggeven als het woord van achter naar voor hetzelfde leest, en anders `false`.
Hoofdletters worden genegeerd: `Lepel` is een palindroom.

De functie moet een `public static` methode zijn van een klasse met de naam `Submission`.

### Voorbeeld

```console?lang=csharp&prompt=>
> Submission.IsPalindrome("lepel")
true
> Submission.IsPalindrome("Dodona")
false
```
