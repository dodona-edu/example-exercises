Write a function `IsPalindrome` that receives a word as argument.
The function should return `true` if the word reads the same backwards, and `false` otherwise.
Capital letters are ignored: `Lepel` is a palindrome.

The function must be a `public static` method of a class named `Submission`.

### Example

```console?lang=csharp&prompt=>
> Submission.IsPalindrome("lepel")
true
> Submission.IsPalindrome("Dodona")
false
```
