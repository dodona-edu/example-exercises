Schrijf een functie `count_vowels` die een tekst als argument aanvaardt.
De functie moet het aantal klinkers (`a`, `e`, `i`, `o` en `u`) in de tekst teruggeven, ongeacht hoofd- of kleine letters.

Schrijf geen `main`-functie: TESTed roept je functie zelf aan.

### Voorbeeld

```cpp
count_vowels("Hello World"); // geeft 3 terug
```
