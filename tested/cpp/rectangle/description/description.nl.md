Schrijf een klasse `Rectangle` die een rechthoek voorstelt.

Als een instantie van de klasse aangemaakt wordt,
worden de breedte en de hoogte (allebei gehele getallen) meegegeven aan de constructor.

Daarnaast moet de klasse de volgende methoden ondersteunen:

- Een methode `area()` die de oppervlakte van de rechthoek teruggeeft.
- Een methode `perimeter()` die de omtrek van de rechthoek teruggeeft.

Schrijf geen `main`-functie: TESTed maakt de instanties zelf aan.

### Voorbeeld

```cpp
Rectangle rectangle(3, 4);
rectangle.area();      // geeft 12 terug
rectangle.perimeter(); // geeft 14 terug
```
