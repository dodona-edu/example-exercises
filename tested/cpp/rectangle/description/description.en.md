Write a class `Rectangle` that represents a rectangle.

When an instance of the class is created, the width and the height (both integers) are passed to the constructor.

The class should also support the following methods:

- A method `area()` which returns the area of the rectangle.
- A method `perimeter()` which returns the perimeter of the rectangle.

Do not write a `main` function: TESTed creates the instances itself.

### Example

```cpp
Rectangle rectangle(3, 4);
rectangle.area();      // returns 12
rectangle.perimeter(); // returns 14
```
