Schrijf een functie `average` die een array van getallen als argument aanvaardt.
Deze functie moet het gemiddelde van die getallen teruggeven.

Gebruik geen `export`: de oplossing wordt samen met de tests gecompileerd.

### Voorbeeld

```console?lang=typescript&prompt=>
> average([1, 2])
1.5
> average([10, 20, 30])
20
```
