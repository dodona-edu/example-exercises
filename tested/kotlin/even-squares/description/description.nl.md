Schrijf een functie `evenSquares` die een lijst van gehele getallen als argument aanvaardt.
Deze functie moet een nieuwe lijst teruggeven met de kwadraten van de even getallen, in dezelfde volgorde als in de oorspronkelijke lijst.

### Voorbeeld

```console?lang=kotlin&prompt=>>>
>>> evenSquares(listOf(1, 2, 3, 4))
[4, 16]
```
