Schrijf een programma dat de naam van de gebruiker vraagt
en vervolgens de gebruiker begroet met de zin `Hallo, [NAAM]!`,
waarbij `[NAAM]` de naam van de gebruiker is.

Het programma moet de naam dus inlezen van standaardinvoer (stdin)
en de begroeting uitschrijven naar standaarduitvoer (stdout).

### Voorbeeld

```console
$ ./programma
Jan
Hallo, Jan!
```

### Eender welke programmeertaal

Dezelfde testen werken in elke programmeertaal die TESTed ondersteunt, Bash inbegrepen.
Deze repository bevat een oplossing in al die talen in de map `solution/`.

Dodona laat per oefening één programmeertaal toe, dus studenten kunnen niet per indiening een taal kiezen.
Een lesgever kiest de taal door `programming_language` in te stellen in `config.json`.
Zolang dat niet gebeurt, staat deze oefening in Python.
