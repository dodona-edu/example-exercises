Schrijf een functie `sum_to` die een geheel getal `n` als argument aanvaardt.
Deze functie moet de som teruggeven van alle gehele getallen van 1 tot en met `n`.
Als `n` kleiner is dan 1, moet de functie 0 teruggeven.

Bouw de som stap voor stap op met een `for`-lus.
Oplossingen die een `while`-lus gebruiken, die de ingebouwde functie `sum` oproepen, of die het antwoord met een formule berekenen, worden niet aanvaard.

### Voorbeeld

```console?lang=python&prompt=>>>
>>> sum_to(5)
15
>>> sum_to(1)
1
>>> sum_to(0)
0
```
