Schrijf een Bash-script dat de naam van een tekstbestand als argument krijgt
en het aantal regels van dat bestand uitschrijft naar `stdout`.

Je mag ervan uitgaan dat het bestand bestaat en dat de laatste regel eindigt met een nieuwe lijn.

### Voorbeeld

```console
$ cat fruits.txt
apple
banana
cherry
$ bash line-count.sh fruits.txt
3
```
