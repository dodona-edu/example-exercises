Write a function `factorial` that receives a non-negative integer `n` as its argument.
The function should return the factorial of `n`: the product of all integers from 1 up to and including `n`.
The factorial of 0 is 1.

Do not start your submission with a `module` line: Dodona adds it for you.

### Example

```console?lang=haskell&prompt=ghci>
ghci> factorial 5
120
```
