Schrijf een functie `sumOfSquares` die een lijst van gehele getallen als argument aanvaardt.
Deze functie moet de som van de kwadraten van die getallen teruggeven.

Begin je oplossing niet met een `module`-regel: Dodona voegt die zelf toe.

### Voorbeeld

```console?lang=haskell&prompt=ghci>
ghci> sumOfSquares [1, 2, 3]
14
```
