# Getting started on Dodona

Content page that explains Dodona to a student who has never used it: the two
kinds of activities, marking a reading activity as read, the submission box of
an exercise, and how to read the feedback afterwards.

Written to be dropped into any course, so it is `access: public` and never
mentions a specific course, series or activity id. Pairs with the exercise
`tested/your-first-submission`, which it points at by name at the end.

The screenshots in `description/media/` are real captures of Dodona (taken
against a local dev instance showing `tested/your-first-submission`), shipped as
light/dark pairs per language and switched with the `light-only` and `dark-only`
classes. They show the new hand-in flow. Recapture them when that UI changes:
the recipe is in the dodona-comms plugin, `skills/dev-and-media.md`.
